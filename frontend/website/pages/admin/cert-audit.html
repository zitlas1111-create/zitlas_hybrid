Certificate Storage Audit

One-off admin tool. Lists every expert_certificates document, classifies its certificateUrl, and lets you reconcile dead legacy records. Runs entirely in the browser against Firestore (this backend has no Admin SDK — same architecture as every other write in ZITLAS). It cannot restore lost files — legacy /uploads/… files were on Render's ephemeral disk and are gone; "reconcile" means removing the dead record so the expert can re-upload cleanly and their Verified badge reflects reality.
